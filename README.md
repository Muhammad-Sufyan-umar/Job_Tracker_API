# Job Application Tracker API

This is a professional Job application tracker Api built in Python using Flask.

This project allow user to apply for job and track his application easily through simple dictionaries
format and it will show output in Json format. 

## Features

* POST endpoint
* GET endpoint
* GET By ID endpoint
* PATCH endpoint
* DELETE endpoint
* Validate Date
* Serializing
* Sort by salary & date
* Search Filter 
* Date range + sort
* Status Filter
* Pagination

## Technologies

* Python 3
* Classes
* Conditional Statements
* Flask
* List
* Loops
* Dictionaries
* Modules

## Purpose of project

This project was created to practice Python with Flask and understand
how Flask and python work together in simple real world.
